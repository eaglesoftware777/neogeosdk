# Audio Provenance

## Generated Effect Bank

The numbered source WAVs in `samples/in_wav_a/` are generated by
`games/skylance/tools/sfx.py`. The synthesizer uses deterministic oscillators,
seeded noise, envelopes and fades; it contains no imported recordings or
adapted melodies. Creator: Eagle Software. Usage follows the repository's
license; these assets are not described as CC0.

`diagnostics/effects.json` records each filename, generation method, source and
encoded SHA-256 hashes, size, source peak/RMS/DC/clipping measurements, and
decoded ADPCM measurements. `diagnostics/decoded/` contains codec reconstructions.

## Researched Sources, Not Imported

- RUOK, Action Game/SHMUP SFX Pack:
  https://opengameart.org/content/action-gameshmup-sfx-pack

These licenses apply to the named packs, not unrelated paid products.

## Independently Composed ADPCM-B Bank

`tools/music.py` defines nine original scores using explicit themes, chord
progressions, bass, synthesized leads and seeded percussion. No recordings or
external melodies were imported. Creator: Eagle Software; repository license.
`samples/in_wav_b/` contains the rendered sources; `samples/out_b/` contains
their aligned encoded data and playback-rate sidecars. `diagnostics/music.json`
records source/encoded hashes and measurements; `diagnostics/music/` contains
decoded previews. These are sampled synthesized compositions, not new
programmed FM/SSG driver tracks.

## Legacy Voice Content Still Present

The unused voice bank predates this pass and was copied from the SDK demo bank.
Its individual authorship and licensing have not been established here.
Completing the programmed FM/SSG soundtrack and replacing unused legacy content
remains required before claiming a complete independent production audio bank.
