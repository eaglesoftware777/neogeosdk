# v1.7.5 status: ng_fight and Shadow League Fighting

Date: 2026-10-12. Published as the v1.7.5 work-in-progress pre-release (SDK
1.7.5, Framework 1.4): the first playable milestone, not the complete v1.7.5
scope below. Sources of the plan: the v1.7.4/
v1.7.5 development directive and the two design documents kept locally in
`docs/specs/` (not tracked).

## Done

- **Engine** `sdk/2d_engine/ng_fight.{h,c}` (opt-in `-DNG_FIGHT=1`, wired in
  the Makefile like `ng_shooter`):
  - Buffered input with negative edge, motions (quarter/half circles, dragon-punch,
    double quarter circles, charge, 360, 720, dash, backdash, simultaneous presses).
  - Super freeze (30-frame screen freeze, backdrop darkening, attacker advantage).
  - Mode-aware cancel logic (chain normal canceling into special/super).
  - Projectiles (spawn, speed, lifespan, clash physics) and striker summon actor.
  - Team sequential (3v3) battle and tag duo mechanics (`ngf_tag_switch`).
  - Hardware camera zoom scale computation (`m->zoom_scale` 192..255).
- **Shadow League Fighting** `games/shadowleague` (id 781), MVS and AES:
  - Title with P2 join, attract demo (CPU vs CPU), 7-fighter select screen with
    pose preview, palette swapping, and country/style readouts.
  - 7-fighter arcade ladder (6 opponents + mirror match closure), arcade continue
    screen with 10-second countdown and MVS credit deduction (`SYS_CREDIT_DOWN`).
  - 2-layer parallax stage (512x224 dojo interior, 512x160 dawn mountains scrolling
    at half-speed), hardware sprite zoom (SCB2 scaling), super freeze backdrop.
  - Complete FIX HUD: health bars, 60s timer, names, 3-stock power gauge, round wins,
    combo counter, guard gauge, spirit bar, and striker status badge.
- **Fighters (7 Total Roster)**:
  - Kenji Arata (Karate, Japan)
  - Jack Mercer (Boxing, USA)
  - Min-Jun Park (Taekwondo, South Korea)
  - Batu Temur (Bökh wrestling, Mongolia)
  - Amara Silva (Capoeira, Brazil)
  - Niran Vong (Muay Lao, Laos)
  - ATLAS (Combat Robotics, Boss Prototype)
- **Character Art Renderer (`tools/fighter_art.py`)**:
  - Anatomical torso definition (pectoral plates, abdominal grid, latissimus V-taper).
  - Uniform overlays (gi lapel, wrestling vest, cybernetic armor chassis, belt ties, abadá cord).
  - Articulated hands (open palm, knife-hand, claw, fist).
  - Hair silhouettes & headgear (spiky, buzzcut, braids, topknot, mongkhon, visor, headbands).
  - Leg anatomy (quadriceps contour, patella, gastrocnemius bulge, flared abadá, ankle wraps).
- **EagleBIOS v1.7.4 Upgrades (`bios/`)**:
  - `SYS_HOWTOPLAY` interactive tutorial screen with 4-button color badges and timer.
  - Common FIX font stream 9 (Japanese text messages).
  - 16-bit JEIDA/PCMCIA memory card support, save list inspection, error buzzer.
  - Backup RAM checksummed format v2 (`EGS2`), automatic v1 migration, corruption recovery.
  - uPD4990A RTC read/write with leap year arithmetic and weekday calculation.
  - 11-entry expanded BIOS menu (Settings, DIPs, Soft DIPs, Memory Card, Diagnostics,
    Sound Test, Input Test, Clock Setup, Cart Info, Backup Clear, Boot Game).
- **Checks**:
  - `python3 -m unittest tests.test_fight tests.test_shadowleague` (774,537 frames simulated across all 7 fighters, 0 errors).
  - `python3 tools/api_freeze.py` (315 frozen prototypes verified).
  - `python3 bios/test_bios.py` (MVS and AES firmware contracts verified).
  - `python3 games/shadowleague/tools/qa.py` (Headless MAME QA passed for both MVS and AES).

## Build and test

```sh
rm out/*.o                                   # shared out/ directory
make GAME=shadowleague all                   # MVS; PLATFORM=aes for the console
python3 games/shadowleague/tools/qa.py       # MVS QA
python3 games/shadowleague/tools/qa.py --platform aes # AES QA
python3 -m unittest tests.test_fight tests.test_shadowleague
python3 bios/test_bios.py                    # EagleBIOS firmware contracts
git checkout -- out sound/driver sdk/sound_voice_ids.h # back to tracked Maiya build
```

## Known limits

- Fighters are drawn by the skeletal renderer: readable and consistent, but
  simpler than hand-painted production sprites.
- The fighter canvas is fixed at 112x128 (7x8 tiles): no per-frame trimming.
- Only the CPU difficulty and round count are operator settings.
- Not run on physical hardware.
