# v1.7.5 status: ng_fight and Shadow League Fighting

Date: 2026-10-12. Version macros are unchanged (1.7.3): this is the first
playable milestone, not the v1.7.5 release. Sources of the plan: the v1.7.4/
v1.7.5 development directive and the two design documents kept locally in
`docs/specs/` (not tracked).

## Done

- **Engine** `sdk/2d_engine/ng_fight.{h,c}` (opt-in `-DNG_FIGHT=1`, wired in
  the Makefile like `ng_shooter`): see `docs/fighting.md`.
- **Shadow League Fighting** `games/shadowleague` (id 781), MVS and AES:
  title, attract demo (CPU vs CPU), fighter select (one or two players), VS
  card, best-of-three matches (soft DIP: 1-3 rounds) against a CPU whose level
  follows the DIFFICULTY soft DIP, round/KO/time-up/perfect announcements,
  GAME OVER, a two-fight arcade ladder ending in CONGRATULATIONS, and a second
  player's START during a match opening a versus match.
- **Fighters**: Kenji Arata (traditional karate) and Jack Mercer (boxing, no
  kicks), each with standing, crouching and air normals, a command attack,
  two throws, three specials, a guard attack, evasive rolls and a level-1
  super. Kenji's counter stance answers a strike with its own follow-up.
- **Art**: skeletal pixel-art renderer (`tools/fighter_art.py`) - 56 and 54
  frames of 112x128; the Arata Mountain Dojo stage (512x224, ten palettes);
  hit/guard/dust effects; FIX life and power bars and large lettering.
- **Sound**: 15 synthesized effects and three tracks (`tools/sound.py`).
- **Checks**: `tests/test_fight.py`, `tests/test_shadowleague.py`,
  `games/shadowleague/tools/qa.py` (MAME, EagleBIOS, MVS and AES).

## Build and test

```sh
rm out/*.o                                   # shared out/ directory
make GAME=shadowleague all                   # MVS; PLATFORM=aes for the console
python3 games/shadowleague/tools/qa.py       # --platform aes
python3 -m unittest tests.test_fight tests.test_shadowleague
python3 games/shadowleague/tools/fighter_cook.py --sheet   # contact sheets
git checkout -- out sound/driver sdk/sound_voice_ids.h     # back to the tracked Maiya build
```

The game's art build (`make GAME=shadowleague art`) validates and cooks the
fighters, so an invalid JSON definition stops the build.

   selection, multi-slot, RAM/VRAM/ROM diagnostics, cartridge verification,
   per-game settings, HOWTOPLAY, 16-bit cards, jukebox; then packaging.

5. Training mode with input display, frame data overlay and replay

6. Continue screen, high scores in backup RAM, story text and endings, one
   boss encounter.
7. Hardware zoom for the stage camera; larger stages with parallax.
8. Release packaging with `tools/make_release.py --game shadowleague
   --game-id 781 --prefix ShadowLeague` and `tools/audit_release.py`.

## Known limits

- Fighters are drawn by the skeletal renderer: readable and consistent, but
  simpler than hand-painted production sprites.
- The fighter canvas is fixed at 112x128 (7x8 tiles): no per-frame trimming.
- Only the CPU difficulty and round count are operator settings.
- Not run on physical hardware.
