## 3. Roadmap claims that did not match the source

`docs/roadmap/SDK_CAPABILITY_AUDIT.md` (2026-10-12) marks some EagleBIOS
features **done** that the code does not do. The v1.7.7 work corrected
`bios/README.md`; the older audit is left as written and is superseded on
these points:

| Older claim | What the source does |
|---|---|
| Real-time clock: uPD4990A serial read/write | a software calendar that starts at a fixed date at power-on and advances with the firmware's VBlank; the chip is not read or set |
| Multi-slot MVS: detection and slot cycling | always slot 0 |
| Memory card: 8-bit and 16-bit detection | 8-bit cards tested; the 16-bit path exists and has never run |
| HOWTOPLAY: animated 4-button tutorial | was a no-op before v1.7.7; now draws the game's own `HTP1` text, or a generic screen |

## 4. Defects found and repaired

Only defects that a build, test or game run exposed:

| Defect | Found by | Repair | Evidence |
|---|---|---|---|
| `MakefileWin32.mak` never built `ng_fight` / `ng_shooter` for games that ask for them | selector work on both makefiles | added their objects as in `Makefile` | Windows makefile parse; Linux unchanged |
| `SYS_HOWTOPLAY` did nothing | v1.7.7 games' attract | game-supplied `HTP1` text block, validated before drawing | `bios/test_bios.py`, games |
| Solitaire deal took 4.6 s and shuffle 2.9 s on the 68000 (every free-tile test scanned all 144 tiles) | Mahjong Demo, frame-counter gap in MAME | per-position counts of tiles on top and beside, updated as tiles go and come back, and a row index; `ng_mjsol_recount()` for hand-made layouts | 0.57 s / 0.42 s; `mahjong_test.c` unchanged results (30 deals 35 ms -> 7 ms host) |
| Paintings quantized into tile-sized colour blocks (skies, roads) | No Signal title and street in MAME | opt-in refit passes in `quantize()` | No Signal screenshots; default path unchanged |
| A screen set up while faded out still dribbled in over several frames (deferred VRAM queue) | No Signal title in MAME | game side: upload directly while dark, then fade in | No Signal and the demo |

Engine bugs fixed while the engines were being written (diagonal slides
into sealed holes, bubble hint results, refunded gears, follower recovery,
NPC presence flags) are covered by the engines' own tests and are not
pre-existing SDK defects.

Known pre-existing condition, not repaired: a Sky Lance P1 build fails when
`sdk/sound_voice_ids.h` was last generated by another game's sound build
(`SOUND_VOICE_WORD_*` undeclared). Building Sky Lance's sound first
regenerates it. Unrelated to v1.7.7.
