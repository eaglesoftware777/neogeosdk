1. game.cfg sanity
- Open game.cfg and set:
CURRENT_GAME=demo
- Confirm the game exists:
  - Linux: make games-list
  - Windows: make -f MakefileWin32.mak games-list

2. Mismatch guard test
- Run with wrong override and confirm it fails:
  - Linux: make GAME=helloworld all
  - Windows: make -f MakefileWin32.mak GAME=helloworld all
- Set CURRENT_GAME=helloworld, rerun, then set back to demo.

3. Linux clean build (full)
- make clean-all
- make all
- make test
- make dump
- make dist

4. Linux stage-by-stage validation
- make clean-all
- make art
- make sfix
- make sound
- make p1
- make test

5. Linux artifact location checks
- Art generated only in game folder:
  - ls games/demo/artbox
  - ls artbox (should be scripts only, no persistent generated files)
- Sound intermediates in game folder:
  - ls games/demo/sound/samples/out_16el_a
  - ls games/demo/sound/samples/out_16el_b
  - ls games/demo/sound/samples/out_a
  - ls games/demo/sound/samples/out_b
- Dump per game:
  - ls dump/demo

6. Windows clean build (full)
- make -f MakefileWin32.mak clean-all
- make -f MakefileWin32.mak all
- make -f MakefileWin32.mak test
- make -f MakefileWin32.mak dump
- make -f MakefileWin32.mak dist

7. Windows stage-by-stage validation
- make -f MakefileWin32.mak clean-all
- make -f MakefileWin32.mak art
- make -f MakefileWin32.mak sfix
- make -f MakefileWin32.mak sound
- make -f MakefileWin32.mak p1
- make -f MakefileWin32.mak test

8. Windows artifact location checks
- Art generated in game folder:
  - dir games\demo\artbox
  - dir artbox (scripts only, no persistent generated files)
- Sound intermediates in game folder:
  - dir games\demo\sound\samples\out_16el_a
  - dir games\demo\sound\samples\out_16el_b
  - dir games\demo\sound\samples\out_a
  - dir games\demo\sound\samples\out_b
- Dump per game:
  - dir dump\demo

9. Multi-game isolation test (recommended)
- Set CURRENT_GAME=helloworld
- Linux:
  - make clean-all && make all && make dump
- Windows:
  - make -f MakefileWin32.mak clean-all && make -f MakefileWin32.mak all && make -f MakefileWin32.mak dump
- Verify separate outputs:
  - dump/helloworld and dump/demo
  - roms/helloworld and roms/demo
  - hash_eagle/helloworld/neogeo.xml and hash_eagle/demo/neogeo.xml

10. Final cleanup verification
- Linux: make clean-all
- Windows: make -f MakefileWin32.mak clean-all
- Confirm no stale intermediates remain in root artbox and global sound/samples generated folders.
